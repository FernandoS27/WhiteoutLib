About the dialects

Warcraft III's engine and the community tool ecosystem each evolved their own MDL text spelling. WhiteoutLib's WarcraftIII dialect matches what the game itself writes (HD layers use a per-layer Shader "name" directive and static TextureID id <= slot, for sub-textures). The HiveWorkshop dialect uses ShaderTypeId N, and named slot properties (NormalTextureID, ORMTextureID, …) instead — compatible with Retera Model Studio, Magos' War3 Model Editor, MdlVis, and mdx-m3-viewer.

Binary .mdx output is unaffected — only the MDL text path uses the dialect setting.

Powered by WhiteoutLib — exception-free, pure WASM, runs in any modern browser.
