## CascLib

CascLib is used as an optional dependency (enabled via `WHITEOUT_ENABLE_CASC`)
to provide read access to Blizzard CASC archives. It is fetched at build time
via CMake FetchContent.

## d4data

The Diablo IV SNO type definitions (`src/whiteout/sno/d4/sno_defs.cpp` and
`src/whiteout/sno/d4/sno_defs.h`) are auto-generated by
`scripts/gen_sno_defs.py` from the `definitions.json` file published by the
d4data project. d4data is not a build-time or runtime dependency; only its
data files are used during code generation.

- **Repository:** <https://github.com/blizzhackers/d4data>
